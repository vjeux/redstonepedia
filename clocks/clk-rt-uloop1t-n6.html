A longer version of the tested clk-rt-uloop1t clock, which pulses every 36 ticks (1.8 s) with 9 blocks; this one is 6 steps longer (n = 6). Each step: add one delay-4 repeater (powered at placement) to each row of the 1-torch inverter U-loop (block A + a dust corner -> top row -> block F -> wall torch on F -> bottom row -> A), which adds 32 ticks (1.6 s) and 4 blocks. Tested in the real game too.

Every clock that pulses every 228 ticks (11.4 s): on the Clocks tab, smallest first (the ones hard to wire into a circuit last).

Try it

It runs by itself: the view plays it; pause and step one tick at a time with the buttons under it. To use it in a circuit, put a repeater where the view puts its lamp: it picks up every pulse.

How this design does it: EXTENDABLE 1-torch inverter U-loop, n = 0 (P = 36 + 32n): U-loop (clk-rt): block A + dust beside it -> top row [delay-4 repeater (powered at placement)] -> block F -> a wall torch on F -> bottom row [delay-4 repeater (powered at placement)] -> A; 1 torch(es) = an inverter loop of delay 18 gt (period 2 x delay)

Its output over time

The output (orange) over the first 456 ticks, as the 3D view plays it: it repeats every 228 ticks (11.4 s), on for 114 ticks (5.7 s) of them. 20 ticks = 1 second.
