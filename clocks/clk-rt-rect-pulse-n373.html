every 6000 ticks (5 min) · 1,504 blocks

Its output pulses by itself every 6000 ticks (5 min), forever. It starts on its own once built.

made of repeater · on for 8 of 6000 ticks

extended (n = 373)starts by itself

every 6000 ticksClock3D view loading (or not available in this browser)

A longer version of the tested clk-rt-rect-pulse clock, which pulses every 32 ticks (1.6 s) with 12 blocks; this one is 373 steps longer (n = 373). Each step: lengthen the 3 x (3+n) ring of delay-4 repeaters with corner blocks by one row: one more repeater on each long side (one pulse loaded at placement), which adds 16 ticks (0.8 s) and 4 blocks. Tested in the real game too.

Every clock that pulses every 6000 ticks (5 min): on the Clocks tab, smallest first (the ones hard to wire into a circuit last).

Try it

It runs by itself: the view plays it; pause and step one tick at a time with the buttons under it. To use it in a circuit, put a repeater where the view puts its lamp: it picks up every pulse.

How this design does it: EXTENDABLE repeater pulse ring, n = 0 (P = 32 + 16n): Rectangle ring (clk-rt): the 3x3 perimeter clockwise from the north-west corner = [b, 4*, b, 4, b, 4, b, 4] (number = repeater delay, * = powered at placement, b = block, d = dust, T = wall torch on the block before it, c = comparator); 0 torches: a pulse ring of loop delay 32 gt

Its output over time

The output (orange) over the first 4000 ticks, as the 3D view plays it (the design names no output, so this is its repeater that turns on most often): it repeats every 6000 ticks (5 min), on for 8 ticks (0.4 s) of them. 20 ticks = 1 second.
