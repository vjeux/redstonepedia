Clock

every 69 ticks (3.45 s) · 13 blocks

Its output pulses by itself every 69 ticks (3.45 s), forever. Built in the game it needs one kick to start (the last block placed); then it keeps going.

Uses a sculk sensor: other sounds nearby (footsteps, another machine) can add pulses, so keep noise away from it.

made of calibrated sculk sensor, note block · on for 10 of 69 ticks

every 69 ticksClockpicture from the real game; the live 3D view replaces it when available

Every clock that pulses every 69 ticks (3.45 s): on the Clocks tab, smallest first (the ones hard to wire into a circuit last).

Try it

The view starts it for you, then it runs by itself: pause and step one tick at a time with the buttons under it. To use it in a circuit, take the signal from its comparator (part of the download, where the view puts its lamp): it reads the clock and passes on every pulse.

How this design does it: Ring of 5 calibrated sensors on a circle (r 12.86), hops [14,13,15,13,14], first resonator a note block (the kick), the others amethyst, 1 wool: each sensor's resonator (amethyst, the first a note block) rings when it fires and the next sensor hears it floor(distance) gt later; the sensor two hops ahead is still dead

Its output over time

The output (orange) over the first 228 ticks, as the 3D view plays it: the grey part is the clock starting up, for 21 ticks (1.05 s); then it repeats every 69 ticks (3.45 s), on for 10 ticks (0.5 s) of them. 20 ticks = 1 second.
