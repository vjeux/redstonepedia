A longer version of the tested clk-rt-rect-inv clock, which pulses every 52 ticks (2.6 s) with 12 blocks; this one is 7 steps longer (n = 7). Each step: lengthen the 3 x (3+n) inverter ring (delay-4 repeaters, corner blocks, a wall torch on one corner block, the next corner dust) by one row: one more repeater on each long side, which adds 32 ticks (1.6 s) and 4 blocks. Tested in the real game too.

Every clock that pulses every 276 ticks (13.8 s): on the Clocks tab, smallest first (the ones hard to wire into a circuit last).

Try it

It runs by itself: the view plays it; pause and step one tick at a time with the buttons under it. To use it in a circuit, put a repeater where the view puts its lamp: it picks up every pulse.

How this design does it: EXTENDABLE 1-torch inverter rectangle ring, n = 0 (P = 52 + 32n): Rectangle ring (clk-rt): the 3x3 perimeter clockwise from the north-west corner = [b, 4, b, 4, b, T, d, 4] (number = repeater delay, * = powered at placement, b = block, d = dust, T = wall torch on the block before it, c = comparator); 1 torch(es): an inverter loop, period 2 x 26 gt

Its output over time

The output (orange) over the first 552 ticks, as the 3D view plays it (the design names no output, so this is its repeater that turns on most often): it repeats every 276 ticks (13.8 s), on for 138 ticks (6.9 s) of them. 20 ticks = 1 second.
