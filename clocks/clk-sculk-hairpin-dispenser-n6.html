Its output pulses by itself every 103 ticks (5.15 s), forever. It starts on its own once built.

Uses a sculk sensor: other sounds nearby (footsteps, another machine) can add pulses, so keep noise away from it.

A longer version of the tested clk-sculk-hairpin-dispenser clock, which pulses every 23 ticks (1.15 s) with 11 blocks; this one is 5 steps longer (n = 6). Each step: one more delay-4 repeater on a stone in each arm of the hairpin (the dust U-turn moves one block out), which adds 16 ticks (0.8 s) and 4 blocks. Tested in the real game too.

Every clock that pulses every 103 ticks (5.15 s): on the Clocks tab, smallest first (the ones hard to wire into a circuit last).

Try it

It runs by itself: the view plays it; pause and step one tick at a time with the buttons under it. To use it in a circuit, put a repeater where the view puts its lamp: it picks up every pulse.

Its output over time

The output (orange) over the first 419 ticks, as the 3D view plays it: the grey part is the clock starting up, for 110 ticks (5.5 s); then it repeats every 103 ticks (5.15 s), on for 10 ticks (0.5 s) of them. 20 ticks = 1 second.

# The hairpin with an empty dispenser as the emitter, diagonal to the calibrated sensor: n delay-4 repeaters out, a two-dust U-turn, n back, an observer firing the dispenser, whose failed dispense comes 16n+6 gt after the sensor fires, heard 1 gt later. Self-starting. P = 7 + 16n gt, 7 + 4n blocks (n = 6: P 103, 31 blocks). Built by `mctas clock sculk family hairpin-dispenser --n 6`.
