Clock

every 50 ticks (2.5 s) · 6 blocks

Its output pulses by itself every 50 ticks (2.5 s), forever. Built in the game it needs one kick to start (the last block placed); then it keeps going.

Uses a sculk sensor: other sounds nearby (footsteps, another machine) can add pulses, so keep noise away from it.

made of calibrated sculk sensor, dispenser, note block, observer, sculk sensor · on for 30 of 50 ticks

Every clock that pulses every 50 ticks (2.5 s): on the Clocks tab, smallest first (the ones hard to wire into a circuit last).

Try it

The view starts it for you, then it runs by itself: pause and step one tick at a time with the buttons under it. To use it in a circuit, put a repeater where the view puts its lamp: it picks up every pulse.

Its output over time

The output (orange) over the first 187 ticks, as the 3D view plays it: the grey part is the clock starting up, for 37 ticks (1.85 s); then it repeats every 50 ticks (2.5 s), on for 30 ticks (1.5 s) of them. 20 ticks = 1 second.
