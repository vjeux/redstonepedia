Its output pulses by itself every 1588 ticks (1 min 19.4 s), forever. It starts on its own once built.

A lamp on its output stays lit: the output is off for only 2 ticks (0.1 s) at a time, and a redstone lamp goes dark only after more than 4 ticks (0.2 s) without power. Redstone dust there follows every pulse.

A longer version of the tested clk-obs-hopclk (one block swapped: 2 versions) clock, which pulses every 20 ticks (1 s) with 17 blocks; this one is 98 steps longer (n = 100). Each step: one more stone in the first hopper (same blocks; up to 5 stacks of 64); sealed: stones over both hoppers, so no dropped item reaches them, which adds 16 ticks (0.8 s) (same blocks). This length was simulated to exactly its period; the base design was tested in the real game.

Try it

It runs by itself: the view plays it; pause and step one tick at a time with the buttons under it. To use it in a circuit, put a repeater where the view puts its lamp: it picks up every pulse.

How this design does it: The compact hopper clock, sealed (period 16N - 12 gt, 17 blocks for 2..320 stones): two hoppers pass N stones back and forth and two sticky pistons move one redstone block between them; stones over both hoppers so no dropped item can reach them (the open 13-block family's timing changes when an item lands on it).

Its output over time

The output (orange) over the first 3180 ticks, as the 3D view plays it: the grey part is the clock starting up, for 4 ticks (0.2 s); then it repeats every 1588 ticks (1 min 19.4 s), on for 1586 ticks (1 min 19.3 s) of them. 20 ticks = 1 second.
