Clock

every 91 ticks (4.55 s) · 9 blocks

Its output pulses by itself every 91 ticks (4.55 s), forever. Built in the game it needs one kick to start (the last block placed); then it keeps going.

Uses a sculk sensor: other sounds nearby (footsteps, another machine) can add pulses, so keep noise away from it.

made of calibrated sculk sensor, comparator, copper bulb, dispenser, oak trapdoor, observer, sculk sensor · on for 49 of 91 ticks

Try it

The view starts it for you, then it runs by itself: pause and step one tick at a time with the buttons under it. To use it in a circuit, put a repeater where the view puts its lamp: it picks up every pulse.
