Clock

every 23 ticks (1.15 s) · 4 blocks

Its output pulses by itself every 23 ticks (1.15 s), forever. Built in the game it needs one kick to start (the last block placed); then it keeps going.

Uses a sculk sensor: other sounds nearby (footsteps, another machine) can add pulses, so keep noise away from it.

made of calibrated sculk sensor, note block, observer, piston · on for 10 of 23 ticks

Every clock that pulses every 23 ticks (1.15 s): on the Clocks tab, smallest first (the ones hard to wire into a circuit last).

Try it

The view starts it for you, then it runs by itself: pause and step one tick at a time with the buttons under it. To use it in a circuit, put a repeater where the view puts its lamp: it picks up every pulse.

Its output over time

The output (orange) over the first 77 ticks, as the 3D view plays it: the grey part is the clock starting up, for 8 ticks (0.4 s); then it repeats every 23 ticks (1.15 s), on for 10 ticks (0.5 s) of them. 20 ticks = 1 second.
