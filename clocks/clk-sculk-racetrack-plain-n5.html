Clock

every 92 ticks (4.6 s) · 24 blocks

Its output pulses by itself every 92 ticks (4.6 s), forever. Built in the game it needs one kick to start (the last block placed); then it keeps going.

Uses a sculk sensor: other sounds nearby (footsteps, another machine) can add pulses, so keep noise away from it.

made of note block, sculk sensor · on for 30 of 92 ticks

extended (n = 5)

every 92 ticksClock3D view loading (or not available in this browser)

A longer version of the tested clk-sculk-racetrack-plain clock, which pulses every 60 ticks (3 s) with 16 blocks; this one is 2 steps longer (n = 5). Each step: one more plain sensor + amethyst block on each straight side, 9 blocks apart (the far turn sensor moves 9 out), which adds 16 ticks (0.8 s) and 4 blocks. Tested in the real game too.

Every clock that pulses every 92 ticks (4.6 s): on the Clocks tab, smallest first (the ones hard to wire into a circuit last).

Try it

The view starts it for you, then it runs by itself: pause and step one tick at a time with the buttons under it. To use it in a circuit, put a repeater where the view puts its lamp: it picks up every pulse.

Its output over time

The output (orange) over the first 317 ticks, as the 3D view plays it: the grey part is the clock starting up, for 41 ticks (2.05 s); then it repeats every 92 ticks (4.6 s), on for 30 ticks (1.5 s) of them. 20 ticks = 1 second.
