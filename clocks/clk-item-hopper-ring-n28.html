A longer version of the tested hopper ring clock, which pulses every 14 ticks (0.7 s) with 4 blocks; this one is 28 steps longer (n = 28). Each step: lengthen the 2-wide hopper ring by one column (2 hoppers), which adds 14 ticks (0.7 s) and 2 blocks. This length was simulated to exactly its period; the base design was tested in the real game.

Every clock that pulses every 406 ticks (20.3 s): on the Clocks tab, smallest first (the ones hard to wire into a circuit last).

Try it

It runs by itself: the view plays it; pause and step one tick at a time with the buttons under it. To use it in a circuit, put a repeater where the view puts its lamp: it picks up every pulse.

How this design does it: Hopper ring with one item: hoppers in a 2-wide ring, each facing the next, one item, a comparator (on stone) reading one hopper.

Its output over time

The output (orange) over the first 819 ticks, as the 3D view plays it: the grey part is the clock starting up, for 7 ticks (0.35 s); then it repeats every 406 ticks (20.3 s), on for 7 ticks (0.35 s) of them. 20 ticks = 1 second.

Notes from its designer

Hopper ring with one item: hoppers in a 2-wide ring, each facing the next, one item, a comparator (on stone) reading one hopper. A hop through an empty hopper is 7 gt (cooldown 8, minus 1 because the sender already ticked), so the item goes around in 7 L gt; n = 0 is the hopper pair (P 14, 4 blocks).
