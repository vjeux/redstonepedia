Clock

every 108 ticks (5.4 s) · 28 blocks

Its output pulses by itself every 108 ticks (5.4 s), forever. Built in the game it needs one kick to start (the last block placed); then it keeps going.

Sounds near its sculk sensor (footsteps, another machine) add pulses: keep noise away from it.

made of note block, sculk sensor · on for 30 of 108 ticks

A longer version of the 16-block clock that pulses every 60 ticks (3 s): 3 steps longer. Each step: one more plain sensor + amethyst block on each straight side, 9 blocks apart (the far turn sensor moves 9 out), which adds 16 ticks (0.8 s) and 4 blocks.

Every clock that pulses every 108 ticks (5.4 s): on the Clocks tab, smallest first (the ones hard to wire into a circuit last).

Try it

Press play under the view to start it; then it runs by itself: pause and step one tick at a time with the buttons under it. To use it in a circuit, put a repeater where the view puts its lamp: it picks up every pulse.

Its output over time

The output (orange) over the first 365 ticks, as the 3D view plays it: the grey part is the clock starting up, for 41 ticks (2.05 s); then it repeats every 108 ticks (5.4 s), on for 30 ticks (1.5 s) of them. 20 ticks = 1 second.
