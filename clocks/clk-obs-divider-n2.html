A longer version of the tested clk-obs-divider clock, which pulses every 12 ticks (0.6 s) with 5 blocks; this one is 2 steps longer (n = 2). Each step: add a stage behind the last bulb: a comparator (facing the clock, reading the bulb, on a stone floor) and a bulb; the tap at the end (a comparator reading the last bulb) moves back with it, which adds 18 ticks (0.9 s) and 3 blocks. Tested in the real game too.

Every clock that pulses every 48 ticks (2.4 s): on the Clocks tab, smallest first (the ones hard to wire into a circuit last).

Try it

The view starts it for you, then it runs by itself: pause and step one tick at a time with the buttons under it. To use it in a circuit, put a repeater where the view puts its lamp: it picks up every pulse.

Its output over time

The output (orange) over the first 144 ticks, as the 3D view plays it: it repeats every 48 ticks (2.4 s), on for 24 ticks (1.2 s) of them. 20 ticks = 1 second.

Design file (15 lines)
name: clk-obs-divider-n2
# Extendable family divider (n = 2): P = 12 x 2^n gt, 5 + 3n blocks. an observer pair (6 gt) toggles the copper bulb behind it on every pulse (12 gt); each comparator reading a bulb powers the next bulb only every other pulse, doubling the period; the last comparator, reading the last bulb, is the output a builder wires. Extension: add a stage behind the last bulb: a comparator (facing the clock, reading the bulb, on a stone floor) and a bulb; the tap at the end (a comparator reading the last bulb) moves back with it. Generator: mctas clock obs family divider --n N --out FILE.
origin: -6 0 0
port output: -7 0 0
