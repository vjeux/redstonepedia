Clock

every 136 ticks (6.8 s) · 12 blocks

Its output pulses by itself every 136 ticks (6.8 s), forever. Built in the game it needs one kick to start (the last block placed); then it keeps going.

Uses a sculk sensor: other sounds nearby (footsteps, another machine) can add pulses, so keep noise away from it.

made of calibrated sculk sensor, comparator, copper bulb, dispenser, observer · on for 68 of 136 ticks

Try it

The view starts it for you, then it runs by itself: pause and step one tick at a time with the buttons under it. To use it in a circuit, put a repeater where the view puts its lamp: it picks up every pulse.

How this design does it: A clock pulsing every 136 gt with an output a builder can wire: the 34 gt clock clock followed by 2 copper-bulb divider stage(s): each bulb toggles on every pulse it gets and a comparator reads it (the comparator is the tap; x 2 per stage).

Its output over time

The output (orange) over the first 475 ticks, as the 3D view plays it: the grey part is the clock starting up, for 67 ticks (3.35 s); then it repeats every 136 ticks (6.8 s), on for 68 ticks (3.4 s) of them. 20 ticks = 1 second.
