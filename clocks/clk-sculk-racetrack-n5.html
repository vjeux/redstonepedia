Clock

every 188 ticks (9.4 s) · 24 blocks

Its output pulses by itself every 188 ticks (9.4 s), forever. Built in the game it needs one kick to start (the last block placed); then it keeps going.

Uses a sculk sensor: other sounds nearby (footsteps, another machine) can add pulses, so keep noise away from it.

made of calibrated sculk sensor, note block · on for 10 of 188 ticks

extended (n = 5)

every 188 ticksClock3D view loading (or not available in this browser)

A longer version of the tested clk-sculk-racetrack clock, which pulses every 60 ticks (3 s) with 8 blocks; this one is 4 steps longer (n = 5). Each step: one more calibrated sensor + amethyst block on each straight side, 17 blocks apart (the far turn sensor moves 17 out), which adds 32 ticks (1.6 s) and 4 blocks. This length was simulated to exactly its period; the base design was tested in the real game.

Every clock that pulses every 188 ticks (9.4 s): on the Clocks tab, smallest first (the ones hard to wire into a circuit last).

Try it

The view starts it for you, then it runs by itself: pause and step one tick at a time with the buttons under it. To use it in a circuit, put a repeater where the view puts its lamp: it picks up every pulse.

Its output over time

The output (orange) over the first 585 ticks, as the 3D view plays it: the grey part is the clock starting up, for 21 ticks (1.05 s); then it repeats every 188 ticks (9.4 s), on for 10 ticks (0.5 s) of them. 20 ticks = 1 second.

# A pure vibration racetrack: calibrated sculk sensors on two straight lines 18 apart (17 between sensors: hop 16) joined by a turn sensor at each end (hops 15); each sensor's resonator (amethyst; the first a note block, right-clicked as the kick) rings when it fires and only the next sensor is within 16. P = 28 + 32n gt, 4 + 4n blocks (n = 5: P 188, 24 blocks). Built by `mctas clock sculk family racetrack --n 5`.
