Details: how it works in depth, our test in the real game, measurements and properties

In depth

It counts input pulses: the output flips once every 576 input pulses: on for 576 pulses, then off for 576. In other words, it divides the number of pulses by 576.

Use it to do something every 576th time, or to slow a fast clock down 576 times.

How to try it

Press play under the view to watch the judge's own test on a loop (the badge reads demo with the step it is on; the same test is drawn as a timing diagram below). Touch any control to stop it and try the circuit yourself.

To try it: press and hold the IN button of the bar (or the cell tagged IN) to power that input; a quick tap sends a short 2 gt pulse.

Inputs are tagged in lime; the output is tagged OUT: the redstone lamp in that cell (the lamp the judge itself adds to read the output) lights while the output is on (the output strip by the demo badge shows its last 40 game ticks, 2 seconds). Drag to look around, pinch or scroll to zoom, step one game tick at a time with the step button.

# CIRCUIT: counter576-items counter 576 N 576, output toggles every 576 pulses, counts one pulse per 1152 inputs (toggles every 576: a square wave, a divider by 1152), 23 blocks, 5x4x3, robust
# Counter 576, 23 blocks, with items (track memory, `mctas circuit memory items --n 576`): the output toggles once every 576 pulses, and the same 23 blocks count any N up to 576; only the number of items loaded changes. Two droppers face each other and hold 576 items between them; each pulse fires only one of them, so the pile walks from one to the other and each runs empty once every 576 pulses. A comparator reads each dropper, and the torch on its output block is lit exactly while that dropper is empty; both torches touch the copper bulb, which therefore toggles each time a dropper runs empty. The bulb is the phase: a comparator reading it powers the stone under the left dropper, which holds it (a dropper kept powered sees no new pulse), and through a dust under the right dropper switches off the torch beside it, which held the right one. The pulse reaches the right dropper through the input block on its lid and the left one through a dust on its own lid.
