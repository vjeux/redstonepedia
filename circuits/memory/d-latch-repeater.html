Details: how it works in depth, our test in the real game, measurements and properties

In depth

A one-bit memory with a data input D and an enable input E. While E is off, the output Q copies D; when E turns on, Q keeps the value D had and ignores D until E is off again (enable low).

How to try it

Press play under the view to watch the judge's own test on a loop (the badge reads demo with the step it is on; the same test is drawn as a timing diagram below). Touch any control to stop it and try the circuit yourself.

To try it: tap the D button of the bar (or the cell tagged D) to turn that input on or off (it powers the cell with a redstone block); tap the E button of the bar (or the cell tagged E) to turn that input on or off (it powers the cell with a redstone block).

Inputs are tagged in lime; the output is tagged OUT: the redstone lamp in that cell (the lamp the judge itself adds to read the output) lights while the output is on (the output strip by the demo badge shows its last 40 game ticks, 2 seconds). Drag to look around, pinch or scroll to zoom, step one game tick at a time with the step button.

Notes from its designer

D latch, 4 blocks: the data input feeds a repeater (on a stone) whose output is q, and the enable input feeds a second repeater pointing into its side. While that second repeater is on, the first is locked and holds q; while it is off, q follows d. So it is transparent while e is OFF; for a latch that follows d while e is ON, hang the 1-block NOT (a wall torch) on the enable input and let it feed the side repeater (5 blocks). Latency 4 ticks.
