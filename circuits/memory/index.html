How we test and rank them

Circuits that remember: on/off memories with a set and a reset input (RS latches), copy-and-hold memories (D latches), clocked memories and counters that react every Nth input pulse. For each function (and each N for counters) we keep the design with the fewest blocks placed.

Built from vjeux/redstonepedia@407bc33a9 on 2026-10-24. Every design was tested in the real game (Minecraft 26.3, tick by tick); the extended clocks listed under a period are longer versions of a tested clock, each tested in the game or simulated to exactly its period.
