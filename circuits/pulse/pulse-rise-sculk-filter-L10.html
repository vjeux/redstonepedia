Details: how it works in depth, our test in the real game, measurements and properties

In depth

When the input turns on, the output gives one short pulse of L = 10 gt (0.5 s), starting 1 gt (0.05 s) after the input turned on. When the input turns off, nothing happens. It handles every input pulse of 2 gt (the shortest a real input makes) or longer.

Use it to turn a lever (which stays on) into a single short pulse, e.g. to fire a piston once.

How to try it

Press play under the view to watch the judge's own test on a loop (the badge reads demo with the step it is on; the same test is drawn as a timing diagram below). Touch any control to stop it and try the circuit yourself.

Notes from its designer

One 10-tick pulse (half a second) every time the input turns on, even for the shortest input (2 ticks), and footsteps or dropped items nearby never set it off: the input makes a note block play, a calibrated sculk sensor (a sound sensor) hears it and switches on for exactly 10 ticks, and a comparator reading a chest tunes the sensor to that one kind of sound. To build it: fill the chest with 1111 items that stack to 64 (17 full stacks and 23 more), so the comparator gives 10 (the number shown over the chest in the 3D view). Good to know: the note block sounds on every rising edge, and that sound is a vibration that sets off other sculk sensors within 16 blocks; the sensor still hears other machines' sounds of the same kind within 16 blocks (another note block, a door or trapdoor opening, a piston pushing, a lever or button switched on); "vibration-proof" means proof against players walking, jumping, dropping, placing and breaking blocks around it. Detail: the note block plays only when it becomes powered (note_block_play, frequency 10); a calibrated sensor with a back signal accepts that frequency only (the lever's block_deactivate is 9, footsteps 1, items landing 2, blocks broken or placed 12 and 13).
