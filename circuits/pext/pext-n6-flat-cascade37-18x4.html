How this design does it: Pushes a block out six cells from a one-block-wide wall, 37 blocks in an 18x4 box: a line of six sticky pistons with a slime block between each pair; each piston fires itself whenever it is moved (an observer rides on top of the slime behind it), and the blocks on the two rows above, run by a chain from the lever, start each wave of pushes (out) or grabs (back).

Details: how it works in depth, our test in the real game, measurements and properties

In depth

Turning the input on pushes a block 6 cells out of the machine; turning it off brings the block back exactly where it was, with nothing left behind. A plain piston only reaches 1.

Extending takes 59 gt (2.95 s), retracting 63 gt (3.15 s).

Our test in the real game

The judge drives the input with this schedule and checks the output after every change; here it is simulated (the 3D view's demo plays the same). Lime: an input is on; orange: the output is on (taller = a stronger signal, 1 to 15). Blue: where the pushed block is, 0 = home, up to N = fully out (the dashed line); it must reach N while the input is on and come all the way back. Time runs left to right in game ticks (20 gt = 1 s).

Swipe the diagram sideways: the whole test lasts 3626 ticks (3 min 1.3 s).

Notes from its designer

Pushes a block out six cells from a one-block-wide wall, 37 blocks in an 18x4 box: a line of six sticky pistons with a slime block between each pair; each piston fires itself whenever it is moved (an observer rides on top of the slime behind it), and the blocks on the two rows above, run by a chain from the lever, start each wave of pushes (out) or grabs (back). How it works: a variant of pext-n6-flat-cascade37 (18x6, which it replaces: same blocks, same extend, faster retract) with the row under the line gone: the observers that make the pistons fire themselves ride on top of the slimes instead of hanging under them, and the search rearranged the wave starters above so nothing moves outside 4 rows. Extend 59 gt, retract 63 gt (the cascade: 59 / 75).
