How this design does it: Pushes a block out three cells from a one-block-wide wall, 18 blocks in a 9x4 box, 27 gt out and 27 gt back: a line of three sticky pistons with a slime block between each pair; each piston fires itself whenever it is moved (observers ride on top of the line), and a row of observers along the top, run from the lever, starts each wave of pushes (out) or grabs (back).

Details: how it works in depth, our test in the real game, measurements and properties

In depth

Turning the input on pushes a block 3 cells out of the machine; turning it off brings the block back exactly where it was, with nothing left behind. A plain piston only reaches 1.

Extending takes 27 gt (1.35 s), retracting 27 gt (1.35 s).

Our test in the real game

The judge drives the input with this schedule and checks the output after every change; here it is simulated (the 3D view's demo plays the same). Lime: an input is on; orange: the output is on (taller = a stronger signal, 1 to 15). Blue: where the pushed block is, 0 = home, up to N = fully out (the dashed line); it must reach N while the input is on and come all the way back. Time runs left to right in game ticks (20 gt = 1 s).

Swipe the diagram sideways: the whole test lasts 1898 ticks (1 min 34.9 s).

Notes from its designer

Pushes a block out three cells from a one-block-wide wall, 18 blocks in a 9x4 box, 27 gt out and 27 gt back: a line of three sticky pistons with a slime block between each pair; each piston fires itself whenever it is moved (observers ride on top of the line), and a row of observers along the top, run from the lever, starts each wave of pushes (out) or grabs (back). How it works: a variant of pext-n3-flat-cascade19 (9x6, 19 blocks, which it replaces: one block fewer, two rows lower, as fast) with the row under the line gone (its observers ride on top of the line) and the wave starters rearranged by the search.
