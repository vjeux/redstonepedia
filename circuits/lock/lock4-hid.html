Its 8 item frames must each hold an item (arrows in the download; any item works): building it by hand, put one in each frame. A right-click turns a frame's item one step of 8.

Try it

Tap a dial's tag in the view (DIAL 1 to DIAL 4) or the frame itself to turn it one step, 8 steps around; the CODE 1 to CODE 4 tags set the code the same way (on a wide screen, the Dial and Code buttons under the view do it too). The output turns on (open) only while every dial shows the same position as its code frame. In the game, right-click a frame to turn it. To open a door with it, run redstone dust from its output (where the view shows the lamp) to the door.

How this design does it: The 4 dials hang on the front (west) face; the code frames hang on the back (east) face, facing away, so a player at the dials sees only the dials and the output, never the code.

Details: how it works in depth, our test in the real game, measurements and properties

In depth

turns its output on only while every item-frame dial shows the same position as its own code frame; set the code by turning the code frames

How to try it

The dials are the item frames tagged DIAL 1 to DIAL 4, the code frames those tagged CODE 1 to CODE 4: tap a tag, or its button under the view, to turn that frame one step (8 steps around). The output, tagged OUT, turns on only while every dial shows the same position as its code frame. Drag to look around, pinch or scroll to zoom.

Notes from its designer

Put any item in each of the 8 item frames; a frame turns through 8 positions, one right-click each. The 4 dials hang on the front (west) face; the code frames hang on the back (east) face, facing away, so a player at the dials sees only the dials and the output, never the code. Set the code from behind by turning the code frames, then turn the dials to match them: the torch at the north end, under the bus, lights (open) only when every dial shows the same position as its code frame, and never for a moment while you turn. Wire a piston door or an iron door to that torch. Inside, per dial: a comparator behind the code frame's block reads the code and powers a block beside the code dust, so the dust carries the code at full value; the dial's comparator passes the dial's value only if it is at least the code (else a torch under its dust lights), and a second comparator passes the code only if it is at least the dial's value (else a torch on its block lights). One dust line under all the torches joins every mismatch into the block under its north end, which turns the output torch off (opens within 6 ticks, closes within 8). A dial takes 3 rows; dials pair up back to back, with one empty row between pairs.
