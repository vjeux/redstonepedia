# CIRCUIT: super-smelter-8 smelter 8 minutes for a double chest 72.2, of the ceiling 100% (72.0 min: 8 furnaces always busy), first ingot by 340 gt, spread 432 each, coal left 64 (64 in the machine), at rest yes, hoppers awake 32, coal needed 496 (the load's 432 and a stack), bill 240 iron, 1 quartz, 30 redstone, 108 blocks, 11x6x4, robust
# B-8, self-clocked (designs/briefs/super-smelter.md, layout B). Per furnace: the input line hopper,
# a locked hopper that takes one raw iron per window, an open hopper under it that drains it into the
# furnace top, a locked side hopper that takes one coal per window from the fuel line, the output
# hopper. The last line hopper faces a comparator: when the line has filled up to it the comparator
# (through a 4 gt repeater: the window opens 8 gt after the last hopper fills, when every line
# hopper holds an item) turns the torch off for a few ticks, unlocking every locked hopper once.
# The next window opens when the line is full again; with the chest empty nothing moves: it rests.
