# CIRCUIT: pext-n12-flat-cascade82-36x4 piston-extender 12 N 12, extend 127 gt, retract 145 gt, 82 blocks, 36x4x1, robust
# Pushes a block out twelve cells from a one-block-wide wall, 82 blocks in a 36x4 box: a line of
# twelve sticky pistons with a slime block between each pair; each piston fires itself whenever it
# is moved (an observer rides on top of the slime behind it), and the blocks on the two rows above,
# run by a chain from the lever (on top of them), start each wave of pushes (out) or grabs (back).
# How it works: a variant of pext-n12-flat-cascade82 (36x6) with the row under the line gone: the
# observers that make the pistons fire themselves ride on top of the slimes instead of hanging under
# them, and the search rearranged the wave starters above so nothing moves outside 4 rows. Extend
# 127 gt, retract 145 gt (the cascade: 129 / 157). Found by three runs of `mctas circuit pext
# anneal --random-pick --free-lever` (random edits judged on redsim; the box of every cell over the
# whole run counts, as in the game): 36x6 -> 36x5 -> 36x4.
