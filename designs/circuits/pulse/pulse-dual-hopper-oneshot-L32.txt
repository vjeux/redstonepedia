# CIRCUIT: pulse-dual-hopper-oneshot-L32 dual-edge L 32 gt, delay 4 gt, min-pulse 60 gt, 13 blocks, 3x3x3, robust
name: pulse-dual-hopper-oneshot-L32
circuit: dual-edge
group: hopper-oneshot-dual
group title: pulse on both edges of any length: a copper bulb and a hopper item timer
group note: L = 8 gt per item in the first hopper: one 13-block design for every L of the form 8n from 16 gt, for inputs about twice as long as the pulse (tested to 40 gt: longer pulses need inputs longer than the judge's longest test)
# One pulse of exactly 8 ticks per item in the first hopper every time the input turns on and every
# time it turns off, for inputs held about twice that long, always 13 blocks: a copper bulb in the
# input cell changes state on both edges, an observer watching it toggles a second copper bulb,
# and while that bulb is lit its comparator locks the second hopper and unlocks the first, so the
# items pass one by one; when the first hopper is empty, its comparator goes off and a torch toggles
# the bulb off; then the items flow back, ready for the next edge. This one holds 4 items: 32 ticks.
# Detail: an edge that comes while the items are still moving toggles the bulb early and cuts that
# pulse short (min-pulse about 2 L: the run plus the items' way back).
