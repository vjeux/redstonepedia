# CIRCUIT: pulse-fall-sculk-filter-L10 falling-edge L 10 gt, delay 1 gt, min-pulse 2 gt (the shortest a real input makes), vibration-proof yes, 5 blocks, 2x2x4, robust
name: pulse-fall-sculk-filter-L10
circuit: falling-edge
# One 10-tick pulse (half a second) every time the input turns OFF, and nothing else: the input
# opens a trapdoor and closes it when it turns off, a sound sensor (calibrated sculk sensor)
# switches on for exactly 10 ticks when it hears the trapdoor close, and a comparator reading a
# chest tunes the sensor to closing sounds only, so the opening, footsteps and dropped items never
# set it off. The smallest vibration-proof 10 gt falling-edge detector (5 blocks), and the first
# falling-edge detector that sees 1-tick inputs.
# Detail: a trapdoor emits block_open (frequency 10) and block_close (9); the chest's 988
# cobblestone make the comparator output 9 into the sensor's back, and a calibrated sensor with a
# back signal accepts that frequency only (a lever's switch-off is 9 too, on the same edge).
origin: 0 0 0
port input: 0 0 0
port output: 3 0 1
