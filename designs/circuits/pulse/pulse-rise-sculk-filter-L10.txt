# CIRCUIT: pulse-rise-sculk-filter-L10 rising-edge L 10 gt, delay 1 gt, min-pulse 2 gt (the shortest a real input makes), vibration-proof yes, 5 blocks, 2x2x4, robust
name: pulse-rise-sculk-filter-L10
circuit: rising-edge
# One 10-tick pulse (half a second) every time the input turns on, and nothing else: the input
# makes a note block play, a sound sensor (calibrated sculk sensor) hears it and switches on for
# exactly 10 ticks, and a comparator reading a chest tunes the sensor to note blocks only, so
# footsteps, dropped items and a lever switching off never set it off. The smallest
# vibration-proof 10 gt rising-edge detector (5 blocks), and it sees 1-tick inputs.
# Detail: the note block plays only when it becomes powered (note_block_play, frequency 10); the
# chest's 1111 cobblestone make the comparator output 10 into the sensor's back, and a calibrated
# sensor with a back signal accepts that frequency only (the lever's block_deactivate is 9,
# footsteps 1, items landing 2, blocks broken or placed 12 and 13).
