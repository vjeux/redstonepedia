# A one-block-wide shulker unloader you can line up side by side with no gap (22 blocks): a
# dispenser drops each full box onto a hopper that empties it, and when the box is empty a piston
# pushes a block into it, which breaks it into a second hopper that sends it on.
# How it works: as the 24-block unloader (a comparator reads the emptying hopper, a copper bulb
# remembers whether the box still has items, a torch fires the piston when it is empty, an observer
# on the piston fires the dispenser after each break, a comparator reading the dispenser starts
# it), with the search's savings: the pushed block is an observer that fires the dispenser itself,
# a lamp and a bulb stand in as the solid blocks, a piston and an observer serve as supports.
# Found by `mctas circuit shulker anneal` (random edits, each judged on redsim with the judge's own
# scenarios) from the 24-block unloader: same box, same badges, same speed.
