# Flushing shulker loader (track shulker, hand-built): the always-on loader plus a partial-box
# flush. A comparator reads the feeding hopper; an observer watching that comparator pulses when
# the hopper runs empty (it is never empty while items flow: it pushes and pulls in the same gt),
# and through a stone and a repeater (delay 2: a 2 gt pulse would make the sticky piston spit its
# stone into the cell) the pulse fires the piston, so the box leaves with whatever it holds when
# the input stops for good (badge flush). When the last item fills a box, both paths fire the
# piston together. The observer also pulses once at the start (the hopper's first item): the stone
# goes through the empty cell and back, which places the first box early. The rest is the always-on
# loader: the dispenser above the box cell, a comparator in compare mode with a redstone block on
# its side (15 only when full), a sticky piston two cells away pushing a stone into the box, the
# drop pushed into a walled cell over the collection hopper, an observer on the pushed stone's cell
# firing the dispenser after each box, and a comparator reading the dispenser through the drop
# cell's roof with an observer firing it when boxes arrive.
