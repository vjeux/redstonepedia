# A one-block-wide unloader you can line up side by side with no gap: a dispenser drops each full
# box onto a hopper that empties it, and when the box is empty a piston breaks it into a second
# hopper that sends it on.
#
# How it works (no redstone dust and no comparator side inputs, so neighbouring copies never
# touch each other's signals):
# - A comparator reads the emptying hopper. That hopper holds exactly 1 item while the box still
#   has items, because it pushes and then pulls in the same tick.
# - When the hopper empties, the torch on the block the comparator powers (through a repeater)
#   lights 3 gt later, and the sticky piston pushes a stone into the box cell. That is soon enough
#   that the emptying hopper is still on its cooldown and cannot grab the box. The box's drop is
#   pushed into the cell above the output hopper, which catches it at once.
# - An observer under the comparator toggles a copper bulb on every change of the comparator, so
#   the bulb is lit while the box has items. While it is unlit, a torch under the block keeps the
#   block powered, which ends the piston's pulse and holds it off until the next box's first item.
#   Every comparator starts at 0, so the design is consistent as placed in any rotation.
# - An observer over the piston, watched by an observer on the dispenser, fires the dispenser
#   after each break. A comparator reads the dispenser through a stone, and two observers watch
#   it. When the dispenser gets its first box, they power the boxes hopper above it, which fires
#   the dispenser by quasi-connectivity. That covers the start and refills after the supply ran out.
