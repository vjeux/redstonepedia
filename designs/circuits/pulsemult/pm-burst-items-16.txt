# CIRCUIT: pm-burst-items-16 burst 16 N 16, pulse 2 gt, period 4 gt, latency 8 gt, span 70 gt, min-pulse 2 gt (the shortest a real input makes), retrigger mixed, repeat > 40 gt, 25 blocks, 7x4x3, robust
name: pm-burst-items-16
circuit: burst 16
# Draft (clk-rt, 2026-10-20): an item burst. Each input gives one output pulse per item in dropper
# D, so the size does not depend on N.
# - The input cell holds copper bulb B0. Its comparator and an observer make one pulse per input
#   rising edge, which toggles bulb B1 on.
# - The comparator reading B1 is R (running). R locks hopper H and powers sticky piston P, which
#   pushes observer B face to face with observer A. The pair chases and B fires D every 4 gt.
#   A's back is the output.
# - When D is empty, its comparator turns off and the torch on its output block lights, toggling
#   B1 off. P pulls B away and H returns the items to D.

port output: 7 4 0
