# CIRCUIT: counter45-items counter 45 N 45, output toggles every 45 pulses, counts one pulse per 90 inputs (toggles every 45: a square wave, a divider by 90), 23 blocks, 5x4x3, robust
# Counter 45, 23 blocks, with items (track memory, `mctas circuit memory items --n 45`): the output toggles once every 45 pulses, and the same 23 blocks count any N up to 576; only the number of items loaded changes. Two droppers face each other and hold 45 items between them; each pulse fires only one of them, so the pile walks from one to the other and each runs empty once every 45 pulses. A comparator reads each dropper, and the torch on its output block is lit exactly while that dropper is empty; both torches touch the copper bulb, which therefore toggles each time a dropper runs empty. The bulb is the phase: a comparator reading it powers the stone under the left dropper, which holds it (a dropper kept powered sees no new pulse), and through a dust under the right dropper switches off the torch beside it, which held the right one. The pulse reaches the right dropper through the input block on its lid and the left one through a dust on its own lid.
