# (tickexact 2026-11-11, ironspec's locker-engagement bridge) a lockable repeater's lock
# engagement: stages, each a delay-1 repeater (d -> out, facing west) locked by a delay-1 repeater

# engages at 32 and releases at 62. Each group of 6 stages has d change at 27..32, so each stage

#   stages 6..11: d high from 10, falls; as 0..5;
#   stages 12..17: d rises; the stage drives a second repeater (so it ticks at the lock's

#   stages 18..23: as 12..17 with the lock from the north;
#   stages 24..29: d high from 10, falls; the stage drives a second repeater, the lock from the
#     north;
#   stages 30..35: as 12..17 with each lock input set before its d in the same gt (the harness
#     applies a gt's input edges in input-name order, so these lock inputs are named a30..a35),
#     so the lock repeater's tick is scheduled first.

# every cell every gt.
