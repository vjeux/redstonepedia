name: cal-slime-bud
circuit: bud
# The classic observer-free BUD, armed by quasi-connectivity: a sticky piston facing up with a slime
# block and a redstone block on top. The redstone block powers the piston only through the block
# above it (quasi-connectivity), and nothing updates the piston when that power is there, so it sits
# armed. Any block update reaching the piston's cell (a block placed, removed or changed next to it,
# or a pure update) makes it re-read its power and extend: the slime block carries the redstone
# block up beside the output for 1 gt; the redstone block no longer powers the piston from up
# there, the landing slime block updates the piston through its head, it retracts and the slime
# block pulls the redstone block back, landing after the slime block, so the piston is armed again
# without having been updated. A shape-only change sends no block update: not detected.
origin: 0 0 0
port target: 1 0 0
port output: 1 3 0
